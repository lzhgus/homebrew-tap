# Homebrew Tap for Awesome Mac Apps

## Install

```bash
brew tap lzhgus/tap
brew install --cask capso
brew install --cask menubloom
brew install --cask agent-kanban
```

Or in one step: `brew install --cask lzhgus/tap/<cask>`.

## Available Casks

| Cask | Description |
|------|-------------|
| [capso](https://github.com/lzhgus/Capso) | Open-source screenshot and screen recording for macOS |
| [menubloom](https://github.com/lzhgus/menubloom) | The right-click menu Finder is missing: New File, Copy Path, Cut & Paste and more |
| [agent-kanban](https://github.com/lzhgus/agent-kanban) | One desktop board for the coding agents you already use |
